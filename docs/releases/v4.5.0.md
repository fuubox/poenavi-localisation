# English

## What's changed

- Merged upstream PoENavi v4.5.0 (from v2.6.2) into the localized edition, including the startup mode selection, Poetrieve price checking on PoE1 and PoE2, Expedition / Desecration / Heist OCR helpers, cheat sheets, map checks, Currency Exchange rates and the updated PoE2 campaign guide.
- Translated the new upstream interface into English and re-synchronized the English PoE1 and PoE2 guides with the updated Japanese guides.
- The language can still be chosen at first launch and changed in Settings; a restart applies the change.
- The "already running" notice is shown in both languages, because it appears before the language setting is read.

# 日本語

## 変更内容

- 本家PoENavi v4.5.0（v2.6.2から）の変更を多言語版に取り込みました。起動モード選択、PoE1/PoE2対応のぽえとれ価格チェック、エクスペディション・冒涜・ハイストのOCR補助、チートシート、マップチェック、カレンシー交換レート、更新されたPoE2キャンペーンガイドなどを含みます。
- 本家で追加された画面を英語に翻訳し、英語版PoE1/PoE2ガイドを更新後の日本語ガイドに合わせて再同期しました。
- 言語は引き続き初回起動時に選択でき、設定画面から変更できます（再起動後に反映）。
- 「起動済み」の通知は、言語設定を読み込む前に表示されるため、日本語と英語の両方で表示します。
